What is being shown?

Every view is calculated from one set of three-dimensional points on a closed curve. Changing the viewpoint rotates those points before drawing them on the screen. Changing Bend or Depth changes the points themselves. Line width changes only how thickly the curve is drawn.

These are orthographic projections: distance from the viewer does not make a part appear smaller. The large view adds depth shading. The small views use a single color, leaving depth less apparent. They are mathematical drawings, rather than photographs of a physical object.

This curve is a geometry demonstration created for Creation OG. Stan Tenen’s work with geometric metaphor and changing silhouettes helped inspire the question.
